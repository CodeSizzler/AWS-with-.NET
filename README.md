# AWS with .NET - Reference Solutions

This repository contains a comprehensive collection of reference solutions, lab instructions, and hands-on examples for integrating **AWS Services** with **.NET Core** and **Web API** applications.

## 🚀 Covered AWS Services
The repo is organized by service, including:
* **Compute**: [AWS Lambda](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20Lambda), [EC2 (Linux)](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20EC2), and [Elastic Beanstalk](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20Elastic%20Beanstalk).
* **Storage & Databases**: [Amazon S3](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20S3) and [DynamoDB](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/dynamodb-dotnet-7-webapi).
* **Identity**: [AWS Cognito](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20Cognito%20with%20.NET%20WebAPI) (WebAPI integration).
* **Messaging**: [Amazon SQS](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/amazon-sqs-for-dotnet-developers-main) and [Amazon SNS](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/amazon-sns-in-30-minutes).
* **Orchestration & Infrastructure**: [AWS Step Functions](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20Step%20Functions) and [AWS CDK](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/AWS%20CDK).

## 🛠 Prerequisites
* [.NET 6/7/8 SDK](https://dotnet.microsoft.com/download)
* [AWS CLI](https://aws.amazon.com/cli/) configured with valid credentials.
* [AWS Toolkit for Visual Studio](https://aws.amazon.com/visualstudio/) or VS Code.

## 📖 How to Use This Repo
1. **Browse by Service**: Navigate to the specific folder (e.g., `AWS S3`) to find the project files.
2. **Follow Instructions**: Look for the `Instructions - [Service Name].md` files inside each directory for step-by-step guides.
3. **Reference Slides**: Check the [Slides](https://github.com/CodeSizzler/AWS-with-.NET/tree/main/Slides) folder for conceptual overviews of AWS Fundamentals.
